# 🍕 Pizza Sales MIS Dashboard (Excel)
Project Overview

This project analyzes 48K+ pizza sales records to generate key business KPIs and build an interactive MIS reporting dashboard in MS Excel. The dashboard simulates real-world sales reporting used for tracking revenue, performance trends, and operational insights.

## Objective

To design an Excel-based reporting solution that:

Tracks revenue and order performance

Identifies peak sales days and hours

Analyzes product and category contribution

Highlights best and worst-selling pizzas

Supports data-driven business decisions

## Tools Used

MS Excel

Pivot Tables

Pivot Charts

Slicers

Conditional Formatting

KPI Cards

Data Cleaning & Aggregation

Basic Excel Formulas

## Key KPIs Tracked

Total Revenue

Average Order Value (AOV)

Total Orders

Total Quantity Sold

Category & Size Contribution %

## Key Insights

1). Highest sales observed during weekends, especially Friday & Saturday evenings.

2). Peak order hours identified between 12 PM – 1 PM.

3). Classic category contributed the highest revenue and total orders.

4). Brie Carre Pizza ranked lowest in both orders and revenue.



## Business Impact

This dashboard demonstrates how Excel can be used as a Management Information System (MIS) tool to monitor sales performance, optimize inventory decisions, and improve operational planning.

1). Leveraged SQL to extract, clean, and organize raw data from multiple sources, ensuring accuracy and reliability. • Utilized Excel's advanced analytics and visualization capabilities to create an interactive and visually compelling sales report.

2). Analyzed sales trends, customer preferences, and peak hours, providing actionable insights for strategic decision-making.

3). Designed intuitive dashboards with slicers, filters, and drill-through options, allowing stakeholders to explore data at various levels of granularity.
